# Download the Labs to Your Local Computer

Follow these steps to download all lab files to your computer:

1. Select **Code**.
2. Select **Download ZIP**.
3. Save the ZIP file to your computer.
4. Extract the ZIP file to a local folder.
5. Open the extracted folder.
6. Upload the files into your OneDrive.
